# Savri Analytics for WordPress

Privacy-friendly website analytics for WordPress. No cookies, GDPR compliant.

## Installation

### Option 1: WordPress.org (Recommended)
1. Go to Plugins → Add New in your WordPress admin
2. Search for "Savri Analytics"
3. Click Install, then Activate

### Option 2: Manual Installation
1. Download the [latest release](https://github.com/savri-io/wordpress-plugin/releases/latest)
2. Upload `savri-analytics.php` to `/wp-content/plugins/savri-analytics/`
3. Activate the plugin through the 'Plugins' menu

### Option 3: ZIP Upload
1. Download `savri-analytics.zip` from [releases](https://github.com/savri-io/wordpress-plugin/releases/latest)
2. Go to Plugins → Add New → Upload Plugin
3. Upload the ZIP file and activate

## Configuration

1. Go to Settings → Savri Analytics
2. Enter your Site ID (find it in your [Savri dashboard](https://savri.io))
3. Choose your API domain (savri.io or besokskollen.se)
4. Enable optional enhanced tracking features

## Features

- **No cookies** - No cookie banner needed
- **GDPR compliant** - Privacy by design
- **Lightweight** - ~2KB script
- **Enhanced tracking** (optional):
  - Outbound link clicks
  - File downloads
  - Form submissions
  - Scroll depth
